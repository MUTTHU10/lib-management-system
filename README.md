# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To develop a Software Requirements Specification (SRS) for a Library Management System that helps manage library activities such as adding books, searching books, issuing books, returning books, maintaining student details, and calculating fines efficiently.

# SRS (Procedure):
1. Introduction: Identify the purpose and scope of the Library Management System.

2. Problem Definition: Develop a system to manage library operations easily and reduce manual work.

3. Functional Requirements: Identify the main functions of the system:
- Add, update, and delete book details.
- Search books by title, author, or book ID.
- Register and manage student details.
- Issue books to students.
- Return borrowed books.
- Calculate fines for late returns.
- Maintain book availability records.
4. Non-Functional Requirements: Define system requirements such as security, reliability, performance, usability, and availability.

5. System Design: Prepare the necessary six UML diagrams to represent the structure and working of the system.

6. Database Design: Identify the required data such as book details, student details, issue records, return dates, and fine details.

7. Testing: Verify that all library operations work correctly.

8. Documentation: Prepare the complete SRS document with all six diagrams.
